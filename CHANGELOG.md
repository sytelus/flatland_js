# Changelog

Notable changes to Flatland are recorded here.

This project follows the structure of [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). It does not currently promise Semantic Versioning or a fixed release schedule.

## Unreleased

### Added

- Repository usage, architecture, contribution, security, and community documentation.
- Dependency-free repository validation command.
- Issue and pull-request templates.
- Editor, line-ending, and ignore rules.

### Changed

- Added language, viewport, and description metadata to the application document.

## Initial repository version - 2026-07-30

### Added

- Initial self-contained Flatland raycasting demo.
- One-dimensional distance-shaded view and two-dimensional reference map.
- Keyboard movement, keyboard and mouse turning, map teleportation, collision clearance, and toggleable help.
